# 使用說明

## 三種內容

### 探索河道

探索河道是目前工作階段的推薦內容。每次開啟會依「設定 → 探索河道設定」重新建立，不會變成使用者保存的河道。系統可以在本機預取下一次探索內容，讓下次開啟更快；這份預取資料不會顯示在清單，也不會匯出或同步。

### 搜尋河道

搜尋、標籤、作者與類似遊戲都使用同一種搜尋河道格式。輸入條件後先形成暫存結果，實際滑過結果或開啟遊戲後才保存。之後可以在「搜尋河道」展開區找到它，並保留上次套用的搜尋篩選。

搜尋結果採用連續載入，不再使用搜尋頁數。電腦版遊戲詳情仍可用左右按鈕或鍵盤左右鍵切換上一款與下一款。

### 清單

清單是長期保存的遊戲集合，包含：

- 收藏
- 願望
- 已購買
- 自訂清單

桌面版會在上方以可橫向拖動的快捷按鈕顯示清單；手機版在側邊展開區顯示。搜尋河道則放在「搜尋河道」展開區，與清單分開。

建立自訂清單時才會出現該次清單的設定；既有清單的名稱與內容可在「設定 → 清單管理」修改。

## 設定頁面

設定分成四頁，先處理常用選項，細節放在對應頁面：

1. **顯示與閱讀**：卡片、主題、字體與閱讀紀錄。
2. **探索河道**：探索排序、篩選與預取相關設定。
3. **清單管理**：管理收藏、願望、已購買、自訂清單，以及匯入清單。
4. **同步與備份**：更新價格資料、JSON 備份與跨裝置同步。

## 網址格式

所有河道使用同一個 `river` 參數：

```text
?river=explore
?river=list:<清單ID>
?river=search:<搜尋ID>
```

開啟特定遊戲時，在網址後加上 `&game=<AppID>`。同步入口另使用 `?sync=<Rentry網址>`；手機預覽使用 `&mobile=1`。

舊的 `q`、`page`、`m` 參數不再使用。搜尋輸入與篩選不會放進網址，搜尋會以河道狀態保存。
