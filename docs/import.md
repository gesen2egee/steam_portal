# 匯入清單

所有匯入都使用同一個流程：提供資料 → 預覽解析結果 → 確認套用。資料可以直接貼上、拖放檔案，或按「選擇檔案」。預覽前不會修改清單。

| 匯入內容 | 位置 | 支援格式 | 套用方式 |
| --- | --- | --- | --- |
| 一般文字清單 | 設定 → 清單管理 → 自訂清單 | 每行一個 App ID 或遊戲網址 | 新增到目前清單 |
| 願望清單 | 設定 → 清單管理 → 願望 | Steam 願望清單 JSON | 取代願望清單 |
| 已購買清單 | 設定 → 清單管理 → 已購買 | Steam 個人遊戲頁 MHTML | 取代已購買清單 |
| Portal 備份 | 設定 → 同步與備份 | Portal JSON | 合併本機資料 |

## 一般文字清單

將每行一個 App ID 或 Steam 遊戲網址貼上，或提供 TXT 檔案。預覽會列出新增、重複與無法辨識的項目；確認後才會加入目前的自訂清單。

## Steam 願望清單 JSON

1. 在設定的願望清單區輸入 SteamID64，產生願望清單網址。
2. 開啟網址並複製完整 JSON，或將 JSON 檔案拖入匯入區。
3. 預覽項目數量與錯誤後，確認套用。

這是完整匯入，因此會取代目前的願望清單。

## Steam 已購買 MHTML

1. 在已登入 Steam 的瀏覽器開啟個人遊戲清單。
2. 將頁面拉到底，確認全部遊戲已載入。
3. 將完整頁面另存為 MHTML。
4. 在已購買匯入區貼上內容、拖放檔案，或按「選擇 MHTML」。
5. 預覽辨識結果後確認套用。

這是完整匯入，因此會取代目前的已購買清單；若頁面可辨識，也會一併保存 SteamID64。

## Portal JSON 備份

在「同步與備份」匯出 JSON，換瀏覽器或裝置後再貼上、拖放或選取 JSON。匯入前會先預覽，確認後合併清單、搜尋河道、閱讀紀錄與設定。

探索河道的當次內容，以及下一次探索的本機預取資料，不會放入備份。

## 手機版

手機版最方便的是貼上內容或按檔案選擇器；若瀏覽器支援，也可以把檔案拖到匯入區。無論使用哪一種方式，都要在預覽確認後才套用。
