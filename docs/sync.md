# 同步與備份

設定中的三個功能用途不同：

| 功能 | 用途 | 是否改動本機資料 |
| --- | --- | --- |
| 更新價格資料 | 重新讀取發布的中央價格快照 | 只更新價格快取 |
| JSON 匯出／匯入 | 手動備份或搬到另一個瀏覽器 | 匯入確認後合併 |
| 跨裝置同步 | 透過 Rentry 讓不同裝置使用同一份資料 | 讀取同步資料後套用 |

## 更新價格資料

「更新價格資料」只重新讀取中央 `data/price.json`。它不會上傳清單，也不會改變收藏、願望、已購買或搜尋河道。

## JSON 備份

建議在更換瀏覽器、清除網站資料或大幅整理清單前，先從「同步與備份」匯出 JSON。匯入時先看預覽，再確認合併本機資料。

備份包含已保存的清單、搜尋河道、閱讀紀錄與設定；不包含探索河道的當次內容，也不包含下一次探索的本機預取快取。

## 跨裝置同步

跨裝置同步會把保存的清單、搜尋河道、閱讀紀錄與設定壓縮後放到 Rentry。第一次使用後，入口網址會記在目前瀏覽器，之後開啟 Portal 會自動讀取一次。

同步入口網址格式如下：

```text
?sync=https://rentry.co/xxxxx
?sync=https://rentry.co/xxxxx&mobile=1
```

同步資料載入失敗時會保留本機資料；舊版本可在設定中的可回復版本還原。探索河道仍會依目前目錄重新建立，不會把預取內容當成已保存資料。

## 安全提醒

Rentry 同步網址包含編輯碼。取得網址的人可以讀取、修改或刪除同步資料，請把它當成密碼保管，不要貼到公開文章、截圖或聊天群組。
