# Steam 玩家心得庫

用來搜尋與閱讀 Steam 遊戲心得的入口。不需要帳號，直接開啟[線上版](https://gesen2egee.github.io/steam_portal/)即可使用。

## 立即使用

1. 搜尋遊戲名稱或 App ID。
2. 從探索河道開始閱讀；實際滑過搜尋結果後，才會保存成搜尋河道。
3. 需要收藏、願望、已購買或自訂清單時，開啟「設定」。

## 三個名詞

- **探索河道**：每次開啟重新推薦，不保存成使用者河道；系統可以預取下一次探索內容。
- **搜尋河道**：搜尋、標籤、作者、類似遊戲的結果；滑過或開啟結果後才保存。
- **清單**：收藏、願望、已購買與自訂清單；會保存，可匯入與同步。

## 版本

- **線上版**：日常使用，首次載入目錄，開啟遊戲時再載入詳情。
- **`steam_portal.html`**：完整離線單檔版。

## 先知道

- 資料保存在目前瀏覽器；更換瀏覽器或清除網站資料前，請先匯出 JSON。
- Rentry 同步網址包含編輯碼，取得網址的人可以讀取、修改或刪除同步資料，請勿公開分享。
