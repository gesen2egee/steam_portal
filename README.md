# Steam 玩家心得庫

這裡同時提供日常使用的 GitHub Pages 版，以及可完整離線開啟的 `steam_portal.html` 單檔版。兩者由同一次建置產生，會使用相同的版本編號與遊戲資料。

## 版本選擇

- GitHub Pages：日常使用的主要入口。首次只下載搜尋、篩選與卡片所需的目錄資料；開啟遊戲後才下載該組詳情。
- `steam_portal.html`：完整離線備份。心得、核心要點、截圖網址與程式都已包含在單一檔案內，可直接以瀏覽器開啟。

Pages 載入時會顯示已下載與總目錄容量。遊戲詳情如果暫時讀取失敗，只會影響該款遊戲，可按「重試載入」，搜尋與其他遊戲不受影響。

## 主要功能

- 以遊戲名稱、App ID、標籤、類型、開發商與發行商搜尋。
- 依價格、折扣、評價、年份、語言與試玩版篩選。
- 使用收藏、閱讀河道、已讀紀錄及自訂清單。
- 以 JSON 匯出或匯入 Portal 狀態備份。
- 從中央 `data/price.json` 顯示價格；手動同步只會重新讀取這份中央快照。

中央價格超過 12 小時或讀取失敗時，Portal 會保留最後一次有效快取並清楚標示過期，不會直接向 Steam 批次請求價格。

## 匯入 Steam 清單

### 已擁有遊戲

1. 在已登入 Steam 的瀏覽器開啟個人遊戲清單。
2. 將頁面拉到底，確認全部遊戲已載入。
3. 把完整頁面另存為 MHTML。
4. 在 Portal 設定的「Steam 清單手動匯入」選擇該 MHTML。

Portal 會取出已擁有遊戲，並在可辨識時一併取得 SteamID64。

### 願望清單

1. 在設定中輸入 SteamID64。
2. 按「產生網址」並開啟願望清單 JSON。
3. 複製頁面回傳的完整 JSON。
4. 貼回 Portal 後按「匯入貼上的願望清單 JSON」。

願望清單與已擁有遊戲匯入會以最後一次完整結果取代對應官方清單；一般自訂清單的文字匯入只會新增項目。

## 資料保存與備份

收藏、河道、閱讀紀錄、清單與設定保存在目前瀏覽器。建議定期使用設定內的 JSON 匯出；更換瀏覽器、清除網站資料或使用不同網址時，再匯入備份。

## 建置與更新

在專案根目錄執行：

```powershell
python build_portal.py
```

一次會完整更新：

- `html/steam_portal.html`
- `steam_portal/steam_portal.html`
- `steam_portal/index.html`
- `steam_portal/assets/` 與 `steam_portal/data/` 的版本化資源

可用參數：

- `--output-root`：Meta 資料來源。
- `--output`：單檔版輸出位置。
- `--release-dir`：Pages 與單檔副本的發布目錄。
- `--limit`：只讀取前 N 份 Meta，供快速測試。

Builder 會先在暫存區產生並驗證全部輸出，確認兩版的 `build_id` 與遊戲數一致後才啟用新版本。Pages 目錄資料上限為 25 MiB。

## 安全與隱私

- Portal 不需要 Steam 密碼，也不會要求輸入帳號密碼。
- 手動匯入只在目前瀏覽器處理選取或貼上的資料。
- 發布前請確認 `data/price.json`、備份檔與其他輸出不含私人資料或憑證。
